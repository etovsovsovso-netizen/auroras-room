# Aurora’s room

Многостраничный сайт таролога Авроры: главная, услуги, история автора, индивидуальное обучение и закрытый клуб.

## Запуск

```bash
pnpm install
pnpm dev
```

## Vercel

Проект готов к прямому импорту из GitHub в Vercel. Команда сборки: `pnpm build`.

Основные Telegram-ссылки и карточки услуг находятся в `src/app/content.ts`.
